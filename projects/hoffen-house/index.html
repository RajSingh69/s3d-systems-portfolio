The project

Hoffen House was my first substantial paid website project after starting S3D Systems. It mattered because it was the point where writing code stopped being just something I could do and became something I was delivering for a paying client.

The project began around an existing Wix presence and moved towards a hand-coded site, with more control over the layout, content and overall presentation. The work also involved deployment, hosting, mobile layouts, search basics and ongoing changes.

What I built

The main website was written in HTML, CSS and JavaScript. It also includes an investor-facing area and valuation-related content; the private parts aren't shown here.

My experience

I remember this as the project that proved to me S3D could be a real business. I was handling the design, coding, deployment and client communication myself. I also deliberately did a lot of the coding manually, which was useful for keeping my skills sharp rather than leaning on tools for every decision.

What I'd take forward

I would make the hosting and media plan earlier. It's easy to concentrate on how a website looks and only deal with image sizes, running costs and SEO near the end. I now see those as part of the build from day one, not things to tidy up afterwards.
